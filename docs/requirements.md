# Требования: поиск сделок для перепродажи

Цель аддона — находить лоты, которые можно выкупить и перевыставить дороже. Аддон показывает список; покупку подтверждает игрок. Режимы добавляются по одному.

## Режим 1: большая скидка

Согласовано 2026-11-13.

### Параметры

| Параметр | Значение |
|---|---|
| Минимальная скидка | 50% |
| Минимальная прибыль | 50 с |
| Максимальная сумма выкупа | 2 з (в настройках от 10 с до 1000 з, шкала логарифмическая) |
| Максимум лотов под выкуп | 10 |
| Минимальное качество | необычное (зелёное) |
| Экипировка со случайными суффиксами | включена, каждый вариант — отдельный предмет |
| Верхнее отсечение | лоты дороже 5 медиан не считаются конкурентами |

Значения по умолчанию лежат в `ns.opts` в `Goldalion/Deals.lua`. Первые шесть параметров меняются в панели настроек; изменения применяются к лотам последнего скана без нового скана.

### Правила

1. **Цена за штуку** = выкуп / количество. Лоты без выкупа пропускаются.
2. **Медиана** — медиана дневных минимумов из истории, если предмет встречался не меньше 3 прошлых дней (сегодняшний не считается); иначе медиана цен текущих лотов.
3. **Отсечение сверху.** Лоты дороже 5 медиан отбрасываются: завышенный лот не может быть опорной ценой.
4. **Дешёвая группа.** Лоты сортируются по цене. Разрыв — место, где лот стоит не больше 50% следующего. Всё, что ниже разрыва, — дешёвая группа, выкупается целиком: оставленный дешёвый лот перебьёт цену перепродажи.
5. **Опорная цена** — цена первого лота над разрывом. Если есть история, берётся меньшее из неё и исторической медианы. Предмет с единственным лотом оценивается только по истории.
6. **Подтверждение.** Опорная цена по соседям принимается, если над разрывом есть второй лот не дороже 120% первого либо у предмета есть история. Пара «10 с и 1 з» без истории сделкой не считается.
7. **Сумма выкупа** — сумма выкупов всех лотов дешёвой группы. Если она больше лимита или в группе больше лотов, чем разрешено, сделки нет.
8. **Прибыль** = количество × опорная цена × (1 − комиссия) − сумма выкупа. Должна быть не меньше минимальной.
9. Если разрывов несколько, выбирается вариант с наибольшей прибылью.

Пример: перчатки за 20 с и 25 с, дальше два лота по 1 з. Группа — два лота, выкуп 45 с, опорная цена 1 з, прибыль 2 × 1 з × 0,95 − 45 с = 1 з 45 с.

### Источник данных

Полный скан (`ReplicateItems`): только он отдаёт отдельные лоты по всему рынку. История — минимум цены предмета за день, 14 дней.

### Допущения, которые надо сверить в игре

- Комиссия 5% взята из Classic.
- Депозит в прибыли не учитывается: считается, что он возвращается при продаже.
- Вариант предмета определяется по ID и названию из ссылки; предполагается, что название включает суффикс.
- Кулдаун полного скана на Forever не измерен.

### Не входит в режим 1

- Оценка скорости продажи.
- Выкуп ступеней у товаров стаками.
- Лоты дешевле цены торговца.

## Интерфейс

- **Главное окно** (`/gold`, по умолчанию открывается вместе с аукционом): кнопка «Сканировать», строка состояния, список сделок по убыванию прибыли. Колонки: предмет, число лотов, сумма выкупа, опорная цена, скидка, прибыль, причина («соседи» или «история»).
- Наведение на строку показывает подсказку предмета. Если у предмета есть варианты с другими суффиксами, в подсказку добавляются их минимум и медиана цены по последнему скану, число лотов и вариантов. Медиана вместо среднего: один завышенный лот сильно искажает среднее.
- Клик по строке ищет предмет в штатном окне аукциона; shift-клик вставляет ссылку в чат.
- **Настройки** — штатная панель игры (кнопка «Настройки» в окне): скидка, прибыль, сумма выкупа, число лотов, отсечение дорогих лотов, минимальное качество, открытие вместе с аукционом.
